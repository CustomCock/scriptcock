{# erwartet: ziel, dateiname, braucht_admin #}

So führst du das Script aus

{% if ziel.value == "powershell" %}
  1. Script herunterladen (landet meist im Ordner Downloads).
  2. Startmenü öffnen, PowerShell eintippen{% if braucht_admin %}, Rechtsklick → „Als Administrator ausführen“{% else %} und öffnen (nicht als Administrator nötig){% endif %}.
  3. Diese Zeile eingeben (erlaubt Scripte nur für dieses eine Fenster):
    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
  4. Script starten:
    & "$env:USERPROFILE\Downloads\{{ dateiname }}"
{% elif ziel.value == "cmd" %}
  1. Script herunterladen (landet meist im Ordner Downloads).
  2. {% if braucht_admin %}Im Explorer Rechtsklick auf {{ dateiname }} → „Als Administrator ausführen“.{% else %}Im Explorer doppelt auf {{ dateiname }} klicken.{% endif %}
  3. Falls Windows SmartScreen warnt: „Weitere Informationen“ → „Trotzdem ausführen“ (nur bei Scripten aus dem Baukasten!).
{% elif ziel.value == "bash" %}
  1. Script herunterladen und ein Terminal öffnen.
  2. Ausführbar machen:
    chmod +x ~/Downloads/{{ dateiname }}
  3. Starten:
    {% if braucht_admin %}sudo {% endif %}~/Downloads/{{ dateiname }}
{% else %}
  1. Script herunterladen und das Programm Terminal öffnen (Programme → Dienstprogramme).
  2. Ausführbar machen:
    chmod +x ~/Downloads/{{ dateiname }}
  3. Starten:
    {% if braucht_admin %}sudo {% endif %}zsh ~/Downloads/{{ dateiname }}
{% endif %}

Am Ende zeigt das Script, wo das Protokoll liegt. Bei Problemen dieses Protokoll an den Support schicken.
