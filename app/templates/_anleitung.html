{# erwartet: ziel, dateiname, rechte (RechteHinweis oder none) #}
So führst du das Script aus {% if ziel.value == "powershell" %}
  1. Script herunterladen (landet meist im Ordner Downloads).
  2. Startmenü öffnen, PowerShell eintippen und öffnen (nicht als Administrator nötig).
  3. Diese Zeile eingeben (erlaubt Scripte nur für dieses eine Fenster):
    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
  4. Script starten:
    & "$env:USERPROFILE\Downloads\{{ dateiname }}"
    5. {% if rechte %}
  5. Das Script fordert für {{ rechte.schritte }} selbst Administratorrechte an – Windows fragt dann nach („Ja“ klicken).
    6. {% endif %}
{% elif ziel.value == "cmd" %}
  1. Script herunterladen (landet meist im Ordner Downloads).
  2. Im Explorer doppelt auf {{ dateiname }} klicken.{% if rechte %} Das Script fordert danach selbst Administratorrechte an – Windows fragt nach („Ja“ klicken).{% endif %}
  3. Falls Windows SmartScreen warnt: „Weitere Informationen“ → „Trotzdem ausführen“ (nur bei Scripten aus dem Baukasten!).
{% elif ziel.value == "bash" %}
  1. Script herunterladen und ein Terminal öffnen.
  2. Ausführbar machen:
    chmod +x ~/Downloads/{{ dateiname }}
  3. Starten (ohne sudo):
    ~/Downloads/{{ dateiname }}
    4. {% if rechte %}
  4. Das Script fragt einmal nach deinem Passwort (sudo) – für {{ rechte.schritte }}.
    5. {% endif %}
{% else %}
  1. Script herunterladen und das Programm Terminal öffnen (Programme → Dienstprogramme).
  2. Ausführbar machen:
    chmod +x ~/Downloads/{{ dateiname }}
  3. Starten (ohne sudo):
    zsh ~/Downloads/{{ dateiname }}
    4. {% if rechte %}
  4. Das Script fragt einmal nach deinem Passwort (sudo) – für {{ rechte.schritte }}.
    5. {% endif %}
{% endif %}

Am Ende zeigt das Script, wo das Protokoll liegt. Bei Problemen dieses Protokoll an den Support schicken.
